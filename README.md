# Restaurant Ordering App

An interactive restaurant menu and food ordering web application built with **React** and **Vite**, deployed on **GitHub Pages**.

- **Live Demo:** https://nangkyalsinthwe.github.io/Restaurant_Ordering_app/

## ✨ Features

- **Menu Browsing:** Displays restaurant food and drink items with prices, descriptions, and visuals.
- **Interactive Order Cart:** Lets users add items, adjust quantities, remove items, and see the live total price.
- **Checkout Flow:** Includes an order completion modal/form for submitting customer details and confirming orders.
- **Responsive Design:** Works cleanly across desktop and mobile screen sizes.

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript (ES6+), HTML5, CSS3
- **Build Tool:** Vite
- **Deployment:** GitHub Pages & GitHub Actions
